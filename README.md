# Gravitation (RootHide Dopamine iOS 16.2 Edition)

Полностью переработанная и исправленная версия культового твика **Gravitation** специально для **Dopamine RootHide** на **iOS 16.2** (iPhone 14 Pro Max / arm64e).

---

## 🚀 Что исправлено по сравнению с оригинальным Gravitation:

1. **Полное устранение бага со смещением иконок при возвращении:**
   - **В оригинале:** Использовался устаревший метод iOS 12 `originForIconAtIndex:` с индексацией по массиву `subviews`. Из-за этого при возвращении иконки путались местами, улетали в координаты `(0, 0)` или смещались.
   - **В новой версии:** Перед запуском физики каждый элемент (иконка, папка, виджет) сохраняет свой точный исходный `center`, `bounds` и `transform` через associated objects. При повторной встряске все элементы плавно возвращаются **ровно на свои исходные места** с помощью spring-анимации, после чего вызывается нативный `layoutIconsNow`.

2. **Полное решение бага с виджетами:**
   - **В оригинале:** Виджеты (появившиеся в iOS 14) не учитывались в логике сетки, их координаты пересчитывались как для иконок 1x1, из-за чего виджеты наползали на иконки и сдвигали всю сетку.
   - **В новой версии:** Виджеты определяются автоматически (`SBHWidgetContainerView` и `SBWidgetIcon`). В настройках добавлен выбор:
     - **Falling Widgets (ON):** Виджеты падают и крутятся вместе с иконками с учетом их реального размера и массы, а затем идеально возвращаются на место.
     - **Falling Widgets (OFF):** Виджеты остаются на месте как твердые физические платформы (`UICollisionBehavior`), от которых отскакивают падающие иконки.

3. **Поддержка Dopamine RootHide и arm64e (iPhone 14 Pro Max):**
   - Конфигурация Theos с флагом `THEOS_PACKAGE_SCHEME = roothide`.
   - Архитектура `iphoneos-arm64e`.
   - Безопасная работа с настройками через `CFPreferences` без конфликтов с песочницей и путями RootHide.
   - Поддержка отскока от **Dynamic Island** (граница Dynamic Island на iPhone 14 Pro Max).

4. **Устранение вылетов и зависаний:**
   - Удалены опасные вызовы `setVisibleColumnRange:` и хаки с памятью, ломавшие рендеринг SpringBoard на iOS 14–16.
   - Блокировка перелистывания страниц (`UIScrollView.scrollEnabled = NO`) во время активной гравитации, что предотвращает выгрузку иконок из памяти.
   - Защита от случайного запуска приложений или перехода в режим редактирования (jiggle mode) при касании падающих иконок.
   - Тактильный отклик (Haptic Feedback) через Taptic Engine при включении и выключении.

---

## 🛠 Управление:

- **Встряхнуть телефон:** Иконки падают и реагируют на физический наклон устройства через акселерометр/гироскоп.
- **Прикосновение к экрану (Finger Gravity):** Иконки притягиваются к вашему пальцу (сила увеличивается при сильном нажатии).
- **Повторная встряска:** Иконки плавно и безошибочно возвращаются на свои места.

## 📦 Сборка через GitHub Actions (рекомендуется):

1. Запустите скрипт `setup_github.bat` в папке твика.
2. Введите имя пользователя GitHub (предварительно создав пустой репозиторий `Gravitation`).
3. Скрипт отправит код в GitHub, где Actions автоматически соберет готовый `.deb` пакет для RootHide.
4. Скачайте `.deb` из вкладки **Actions** и установите через Filza / Sileo.

## 💻 Локальная сборка на macOS/Theos:

```bash
make clean
make package FINALPACKAGE=1 THEOS_PACKAGE_SCHEME=roothide
```
